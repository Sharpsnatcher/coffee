## Как запустить

1. Положить `Coffee Shop Sales.xlsx` в папку с программой.
2. Установить библиотеки: `pip3 install pandas numpy openpyxl`
3. Запустить: `coffee.py`
4. Ввести порог цены (например, `3`) и категорию (например, `Coffee`).

## Выводы

1. **Чтение данных.** 149 116 продаж, 11 колонок, пропусков нет. Цены от 0.80 до 45.00.
2. **Фильтрация.** Цена больше 3, категория Coffee — подошло 22 468 строк.
3. **Группировка.** Самая дорогая категория — Coffee beans, самая дешёвая — Flavours. Больше всего продаж у Coffee и Tea.
4. **Новый столбец.** Средняя цена 3.38. Выше среднего — 53 009 строк, ниже или равно — 96 107.
5. **NumPy.** Среднее 3.38, отклонение 2.66, максимум 45.00, минимум 0.80. После нормализации цены от 0 до 1.
6. **Сохранение.** Результат сохранён в `processed_coffee.csv`.
