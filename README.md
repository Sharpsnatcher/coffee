# ДЗ 2. Анализ продаж кофейни "Кофе и Python"

## Как запустить

1. Положить `Coffee Shop Sales.xlsx` в папку с программой.
2. Установить библиотеки: `pip3 install pandas numpy openpyxl`
3. Запустить: `python3 coffee_analysis.py`
4. Ввести порог цены (например, `3`) и категорию (например, `Coffee`).

Если ввести не число или несуществующую категорию, программа попросит ввести ещё раз.

## Выводы

**1. Чтение данных.** В таблице 149 116 продаж и 11 колонок, пропусков нет.
Цены от 0.80 до 45.00, средняя цена 3.38.

**2. Фильтрация.** Порог цены 3, категория Coffee. Подошло **22 468 строк**.

**3. Группировка.** Самая высокая средняя цена у Coffee beans (21.02), самая низкая у Flavours (0.80).
Больше всего продаж у Coffee и Tea: это недорогие напитки.

**4. Новый столбец.** Цена выше средней (3.38) у 53 009 строк, ниже или равна у 96 107.

**5. NumPy.** Среднее 3.38, стандартное отклонение 2.66, максимум 45.00, минимум 0.80.
После нормализации цены стали от 0 до 1. Большинство значений близко к 0, потому что почти все товары намного дешевле 45.

**6. Сохранение.** Результат сохранён в `processed_coffee.csv` с новым столбцом `price_level`.
